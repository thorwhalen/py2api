py2api.examples.wrapping_a_class

Run this file and try it out with curl or in a browser.

Examples

http://0.0.0.0:5003/my_ws?attr=greet http://0.0.0.0:5003/my_ws?attr=greet&user=me http://0.0.0.0:5003/my_ws?attr=greet&dflt_greeting=Goodnight http://0.0.0.0:5003/my_ws?attr=greet&dflt_greeting=Goodnight&user=day http://0.0.0.0:5003/my_ws?attr=fcalc.whoami http://0.0.0.0:5003/my_ws?attr=icalc.compute&_help=1 http://0.0.0.0:5003/my_ws?attr=fcalc.compute&x=5&y=3&op=/ http://0.0.0.0:5003/my_ws?attr=icalc.compute&x=5&y=3&op=/ http://0.0.0.0:5003/my_ws?attr=fcalc.compute&x=5&y=3&op=-

See that for the “+” operation, you need to urlencode (as %2B):

http://0.0.0.0:5003/my_ws?attr=fcalc.compute&x=5&y=3&op=%2B

See that

http://0.0.0.0:5003/my_ws?attr=fcalc.whoami

will raise a ForbiddenAttribute error, since it wasn’t “registered” as a permissible_attr.

Note that you can also check out tests/wrapping_a_class.py to see what is expected.
